# 🇬🇭 Ghana COVID-19 Data Analysis

A comprehensive data analysis 
comparing Ghana's COVID-19 
performance against ALL 54 
African countries using real 
world data from Our World In Data.

## 🔗 Live Dashboard
[Click here to view live app](https://ghana-covid-19-dashboard-solomon-kok-nanleeb.streamlit.app/)

## 📊 Key Findings

### Ghana Overview
| Metric | Value |

### Africa Rankings

## 🔍 Key Insights

1. Ghana ranked #17 in cases
   out of 54 African countries
   
2. Ghana achieved TOP 5 lowest
   death rate in all Africa
   
3. Christmas 2021 (Dec 26) was
   Ghana's worst single day
   
4. Vaccines reduced deaths by
   86.4% — from 1,287 to 175
   
5. Zero COVID deaths in 2024
   — pandemic essentially over
   
6. Only 0.51% of population
   got COVID — excellent
   management!
